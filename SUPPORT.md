# Support

Easy Ads Integration Validator is a static analysis tool. Support answers are limited to the documented CLI, MCP, report, policy, and Unity MAX or LevelPlay workflows.

## Before Asking For Help

1. Check the [quickstart](docs/quickstart.md), [configuration guide](docs/configuration.md), and profile documentation.
2. Confirm the installed version and target framework.
3. Re-run the smallest command that demonstrates the problem.
4. Remove credentials, app identifiers, customer data, and proprietary source before sharing output.

## Where To Ask

- Use the bug-report form for a reproducible defect.
- Use the feature-request form for a proposed capability or workflow change.
- Use a discussion or issue for documentation and usage questions when no private information is involved.
- Report suspected vulnerabilities according to [SECURITY.md](SECURITY.md), not through public support channels.

Please include the command, operating system, tool version, relevant profile, and redacted report or error output. The tool cannot verify dashboard configuration, runtime behavior, devices, emulators, simulators, or generated Unity builds.
